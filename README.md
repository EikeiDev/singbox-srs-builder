# singbox-srs-builder

> 🌐 Конвертируй список доменов в Rule Set для sing-box — прямо в браузере, без сервера.

**[→ Открыть инструмент](https://eikeidev.github.io/singbox-srs-builder/)**

---

## Что это?

Одностраничное веб-приложение: вставляешь список доменов — получаешь готовый файл Rule Set для **sing-box** (`.json` или бинарный `.srs`).

Ничего не устанавливать. Никаких зависимостей. Данные никуда не отправляются.

## Возможности

- **Вставь и конвертируй** — один домен на строку, результат сразу
- **Типы правил** — `domain_suffix`, `domain`, `domain_keyword`, `domain_regex`
- **Версии формата** — Rule Set v1 и v2
- **Умная очистка** — удаление дубликатов, убирает ведущую точку, сортировка
- **Поддержка комментариев** — строки, начинающиеся с `#`, игнорируются
- **Скачать** или **скопировать** результат

## Использование в sing-box

После скачивания `.json` файла, подключи его в конфиге:

```json
{
  "rule_set": [
    {
      "type": "local",
      "tag": "my-rules",
      "format": "source",
      "path": "./custom-rules.json"
    }
  ]
}
```

Для компиляции в бинарный `.srs` (лучше производительность):

```bash
sing-box rule-set compile custom-rules.json
```

После этого измени `"format"` на `"binary"` и `"path"` на `"custom-rules.srs"`.

## Формат ввода

```
# Это комментарий
google.com
youtube.com
.example.org       # ведущая точка тоже поддерживается
github.com
```

## Запуск локально

Это один файл `index.html` — можно разместить где угодно:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
