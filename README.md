# singbox-srs-builder

> 🌐 Конвертируй список доменов в бинарный `.srs` файл для sing-box — прямо в браузере, без сервера.

**[→ Открыть инструмент](https://eikeidev.github.io/singbox-srs-builder/)**

---

## Что это?

Одностраничное веб-приложение: вставляешь список доменов — скачиваешь готовый бинарный **`.srs`** файл для sing-box Rule Set.

Ничего не устанавливать. Никаких зависимостей. Данные никуда не отправляются.

## Возможности

- **Вставь и скачай** — один домен на строку, компиляция прямо в браузере
- **Типы правил** — `domain_suffix`, `domain`, `domain_keyword`, `domain_regex`
- **Версии формата** — Rule Set v1 и v2
- **Умная очистка** — удаление дубликатов, убирает ведущую точку, сортировка
- **Поддержка комментариев** — строки, начинающиеся с `#`, игнорируются

## Использование в sing-box

```json
{
  "rule_set": [
    {
      "type": "local",
      "tag": "my-rules",
      "format": "binary",
      "path": "./custom-rules.srs"
    }
  ]
}
```

## Формат ввода

```
# Это комментарий
google.com
youtube.com
.example.org
github.com
```

## Запуск локально

Это один файл `index.html` — можно разместить где угодно:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
